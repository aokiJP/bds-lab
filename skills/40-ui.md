# 40. フォーム（@minecraft/server-ui）

```js
import { ActionFormData, ModalFormData, MessageFormData } from '@minecraft/server-ui';

const form = new ActionFormData()
  .title('メニュー')
  .body('選んでください')
  .button('飛ぶ')
  .button('やめる');

const res = await form.show(player);
if (res.canceled) return;
console.warn(`TAG choice=${res.selection}`);
```

| クラス | 何 |
|---|---|
| `ActionFormData` | ボタンを並べる |
| `ModalFormData` | 入力欄・スライダー・トグル・ドロップダウン |
| `MessageFormData` | はい / いいえ |

## 効かせるための決まり
- `show` は `async`。**イベントの中から直接呼ぶと出ません**（画面が閉じられていない扱い）。
  `system.run(() => form.show(player))` で 1 tick ずらしてください
- 相手が画面を開いている間は出ません。`res.cancelationReason` が `UserBusy` なら、少し待って出し直します
- `ModalFormData` の `res.formValues` は**並べた順の配列**です。名前ではありません

## 検証でどう確かめるか
フォームは画面なので、SimulatedPlayer では押せません。
**「フォームを出そうとしたこと」をログに 1 行出して、そこを見てください。**

```js
console.warn('TAG form-open');
```
押したあとの挙動は、`/scriptevent` で同じ処理を呼べるようにしておくと、実機で確かめられます。
