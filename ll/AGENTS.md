# ll lab: a LeviLamina mod (LegacyScriptEngine, TypeScript) proven on a real LeviLamina server (Windows BDS; Wine 10 on Linux, fetched by itself). `node lab.mjs ll <cmd>` once, then `node lab.mjs <cmd>`
1. `new <n> "Title" "<request>" desc="<what it does>"` → mods/<n>/: manifest.json, src/main.ts (a command + onJoin; bundled to one file), tests.txt, TASK.md (`--js`, `--native` C++, `--bp` packs).
2. Write src/main.ts and tests.txt (syntax and `@A` real-player actions: ../AGENTS.md). What only LeviLamina can do, as 14 working mods in mods/: `help ideas`.
3. `go` = types (@levimc-lse/types) → tests on a fresh server → QA (3 players, rejoin, /reload, restart, perf, still running) → dist/<n>-<ver>.zip. Fix what it prints until `DONE`.
LSE (QuickJS, no Node APIs): commands `const c = mc.newCommand('n', 'desc', PermType.Any); c.mandatory('x', ParamType.Int); c.optional('t', ParamType.RawText); c.overload(['x', 't']); c.setCallback((_c, origin, out, r) => out.success('..')); c.setup()` (origin.player may be null; out.error(..)). Events `mc.listen('onJoin', (pl) => ..)` (return false cancels before-style ones); setTimeout/setInterval; pl.tell/realName/blockPos/getDevice(); mc.getOnlinePlayers()/getPlayer(name)/runcmdEx(cmd); files under ./plugins/<n>/ (File, JsonConfigFile, DBSession sqlite3). Offline servers: pl.xuid is empty. Look up, do not guess: `api <Name|Name.member|onEvent|?word>`.
Expectations under a `lse` line check its value only (`@A ...` ones still the section). Test lines besides console commands (`ll list`) and `@A` actions: `lse <code>` inside your mod (`return x`, async ok; more lines: `\n`, or the next lines indented by 2 spaces; mc ll p(name) run("cmd") inv(p) block(x,y,z) $) · `serverping` · `events on [onJoin]` · `bots <n>` (server-side simulated players) · `lag <ms>` · `watch <expr>` · more: `help lse|events|reload|native|wine|server|player|tests`.
Permissions: the lab's players are operators; `deop B` for a "not allowed" section. `restart` keeps plugins/<n>/ and the world; players rejoin. `tp A 3 -60 -7` puts A on the block centre (3.5, -60, -6.5).
World: flat (grass y=-61), x,z -32..31 loaded, survival, noon, no mob spawns. Under Wine a player's action takes ~1 s: the lab waits for each by itself.
