## loads
ll list
~ warps
## no warps yet: /warps says so
@A join
@A cmd /warps
~ ^@A .*ワープ地点はまだありません
## an OP sets a warp where they stand with /setwarp <name>
tp A 10 -60 5
wait 1000
@A cmd /setwarp home
~ ^@A .*ワープ地点「home」を作成しました: 10\.\d, -60, 5\.\d \(overworld\)
## anyone (a non-OP player too) warps there with /warp <name>
@B join
deop B
tp B -20 -60 -20
wait 1000
@B cmd /warp home
~ ^@B .*「home」へワープしました
wait 1000
lse const q = p('B').feetPos; return [Math.floor(q.x), Math.round(q.y), Math.floor(q.z)].join(',')
= 10,-60,5
## /warps lists every warp for anyone
@A cmd /setwarp 広場
~ ^@A .*「広場」を作成しました
@B cmd /warps
~ ^@B .*ワープ地点 \(2\): home \[10\.\d, -60, 5\.\d \(overworld\)\] \| 広場 \[
## a player can warp only once per 10 seconds
tp B -20 -60 -20
wait 500
@B cmd /warp 広場
~ ^@B .*ワープはあと([1-9]|10)秒待ってください
!~ ^@B .*「広場」へワープしました
wait 1000
lse const q = p('B').feetPos; return Math.floor(q.x)
= -20
wait 9000
@B cmd /warp 広場
~ ^@B .*「広場」へワープしました
## the cooldown is per player: A can still warp
@A cmd /warp home
~ ^@A .*「home」へワープしました
## a non-OP cannot /setwarp or /delwarp
@B cmd /setwarp trap
!~ 「trap」を作成しました
@B cmd /delwarp home
!~ 「home」を削除しました
lse return Object.keys(JSON.parse(File.readFrom('./plugins/warps/warps.json'))).sort().join(',')

!~ trap
