## a muted player can neither chat nor whisper (/tell /msg /w /me)
@A join
@B join
mute B 5
~ B muted for 5 min
@B chat hello everyone
~ ^@B .*You are muted \(\d+s left\)
!~ ^@A .*hello everyone
@B cmd /tell A secret
!~ ^@A .*secret
@B cmd /msg A secret2
!~ ^@A .*secret2
@B cmd /me waves
!~ ^@A .*waves
~ ^@B .*You are muted
## other players still talk, and /unmute gives the voice back
@A chat hi B
~ ^@B .*hi B
unmute B
~ B can talk again
@B chat back again
~ ^@A .*back again
## short aliases run the real command
@A cmd /night
wait 500
lse return mc.getTime(0)
~ ^1[3-9]\d{3}$
@A cmd /gmc
wait 500
lse return mc.getPlayer('A').gameMode
= 1
## every command is logged with the time and place
lse const l = File.readFrom('./plugins/cmdguard/commands.log').trim().split(String.fromCharCode(10)); return l.slice(-2).join(' | ')
~ ^\d{4}-\d\d-\d\d \d\d:\d\d:\d\d A -?\d+ -?\d+ -?\d+ /gmc \| .* A .* /gamemode creative$
lse return File.readFrom('./plugins/cmdguard/commands.log').split('/tell A secret').length - 1
= 1
