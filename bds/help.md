## add
`node lab.mjs add item|block|entity <ns:id> "Name" [ja=名前] [tex=<shape>[:RRGGBB]] [states=<json>] [drops=<item>[*n|*min-max],..] [<component>=<json>..]` writes every file the game needs: the bp definition (format_version 1.21.90: custom components go straight into "components"), the rp texture/atlas entry, the name in every language of rp/texts/languages.json, a drawn 16x16 texture; entities also get a client entity, a box model and a spawn egg name. A component name the game does not know is flagged at once (did you mean ...).
Components: a bare name means minecraft:<name>; `ns:x={}` is a custom component (register it: kit onItem/onBlock). Run again with other components to add them; existing files are kept.
- item: `max_stack_size=16` `food='{"nutrition":4,"saturation_modifier":0.6,"can_always_eat":true}'` (+ `use_modifiers='{"use_duration":1.6}'`) `durability='{"max_durability":250}'` `damage=5` `hand_equipped=true` `glint=true` `cooldown='{"category":"wand","duration":1}'` `lab:wand={}`
- block: `states='{"lab:lit":[false,true]}'` then permutations by hand (bp/blocks/<id>.json: "permutations":[{"condition":"q.block_state('lab:lit')","components":{"minecraft:light_emission":15}}]), set it in scripts: b.setPermutation(b.permutation.withState('lab:lit', true)); `light_emission=15` `destructible_by_mining='{"seconds_to_destroy":0.5}'` `friction=0.4` `lab:toggle={}` (onBlock('lab:toggle',{onPlayerInteract(e){...}})) `drops=lab:gem*1-3`
- entity: `health='{"value":6,"max":6}'` `movement='{"value":0.15}'` `attack='{"damage":3}'` `drops=lab:gel*1-2,minecraft:bone*0-1` `scale=0.6` `collision_box='{"width":0.6,"height":0.6}'`; behaviour: `behavior.melee_attack='{"priority":2}'` `behavior.nearest_attackable_target='{"priority":1,"entity_types":[{"filters":{"test":"is_family","value":"player"}}]}'` (the default already strolls and looks at players).
Textures: gem ingot orb apple sword pickaxe axe shovel hoe coin key potion dust stick wand heart star book scroll | blocks: block ore bricks planks glass. Look at vanilla: `sample <word>`; component fields: `doc minecraft:<component>`.
