# 依頼 — bds-lab を「読む量」で作り直す

いまの bds-lab は動きます。遅いのは AI の側で、**読ませる量が多すぎる**。そこだけを削ります。機能追加ではありません。

**先に読むのはこの 2 つだけ**（合計 3,459 tok）: `docs/TOKENS.md`（実測値）と `docs/QUESTIONS.md`（消してはいけない情報）。
`ROADMAP.md` は人向けで 8,697 tok あります。**全部読まないでください。**「はじめに直す 5 件」と #36 だけで足ります。

## いまの状態（`docs/CHANGES.md`）

済んだのは A（`npm run api` 33〜59 tok）・C（`npm run status` 51 tok）・バグ 3 件（#17 #21 #36）・
常駐の一本化。10 問は 294,564 → **2,340 tok（126×）**、正答 10/10。

## 0. 先に測る（飛ばさない）

`npm run tokens`（中身は `docs/tokens.mjs`）を実行し、**`docs/TOKENS.md` の「改修後」が ±10% で再現すること**を確かめてください。
再現しないなら測り方が変わっています。倍率を書く前に直すこと。

## 1. やること（効果の大きい順）

**D. 返す量を減らす（「全文で返す」を廃止）**
検索置換ブロックか unified diff。適用側で厳密に検証し、失敗は 5 行以内の理由で返す。2KB 未満だけ全文可。
`src/run/apply.mjs` の `validate()`（構文・省略・入口の検査）はもう入っているので、その隣に置く。

**B2. skills を 1 枚 300 tok に割る**
`npm run skill <語>` は当たるカードだけ出せるようになった。残りはファイルの分割と、
版・出典 URL・最終確認日の frontmatter（`npm run skill -- stale` で古いものを出す）。

**E. 実機を回す前に落とす**
`npm run lint`：使っている API を `src/run/api.mjs` の索引と突き合わせ、「この版に無い」を BDS 起動なしで落とす。
変更に関係する仕様書だけ再実行（内容ハッシュ）。`TASK.md` の受け入れ条件から仕様書の雛形を生成。

**A2. `real` を版に追従させる（#1・#2）**
`realplayer.mjs` の `2193` / `1.26.51` を定数にし、既定を `detectProtocol` の結果にする。
`bedrock-protocol` の版を固定して lockfile を置き、パッチが当たったかの確認を `npm run selftest` に足す。

## 2. もっと良い方法を探す（必須・5 案以上）

**案 / 削減見込み（実測） / 実装コスト / 壊れやすさ** の表にして、上位 2 つを実装してください。**測れない案は採らない。**
出発点: MCP tool 化（api・status・check を文書ではなく呼ばせる）／ 型定義の用途別ビュー ／ 失敗コード表（`E012` → 直し方）／ 仕様書の DSL（1 条件 1 行）／ 実機の失敗から落とし穴カードを自動生成 ／ 固定 → 可変の並び（プロンプトキャッシュが効く）

## 3. 禁じ手（やったら失敗）

- 数え方を変える・測る対象をすり替える
- **情報を消して減らす**（`docs/QUESTIONS.md` が 1 問でも落ちたら失敗）
- 人向けの `README.md` を削って数字を作る（README は対象外）
- 機能を削る・仕様書を緩める・`--full` のような逃げ道を用意せずに情報を捨てる

## 4. 壊さない

- **先に `ROADMAP.md` の #36 を直す**（`specs/` が全アドオン共通で読まれ、別アドオンの仕様書が必ず落ち、「今回から壊れた」と誤報する）
- `npm run selftest` は常に通す（いま 29/29）。新しいコマンドには selftest を足す
- `tools/` は触らない。`specs/` は通すために緩めない
- BDS の起動を遅くしない（いま: 作り置きの世界から 1.8 秒）
- `vendor/bedrock-server.zip` は git にも handoff zip にも入れない。handoff zip は今より小さく
- 依存を増やさない（増やすなら 1 行で理由）。Node 20 以上・macOS（Apple Silicon）で動く
- 索引は `npm run docs` / `npm run update` で再生成され、版が上がっても古くならないこと
