# GitHub の時間を借りる（ホスト）

[README](../../README.md) から分けた詳細です。全体の地図は [ARCHITECTURE.md](../ARCHITECTURE.md)。

試験に使う GitHub Actions の時間を、知り合い（貸し手）が自分のアカウントの分から貸してくれるときの仕組みです。貸し手は
自分のアカウントに private のリポジトリ（ホスト）を作り、あなたを collaborator に招きます。ラボは **あなた自身の GitHub の
ログイン**（`gh`）で、そのホストに「ラボを送る → 試験を走らせる → 結果を受け取る」を、貸し手が決めた上限の中でだけ行います。

## 決まりごと（GitHub の規約から）

- 1 人が持てる無料のアカウントは 1 つ、ログインは 1 人だけが使います。なので **アカウントを増やす形も、貸し手のアカウントに
  ログインする形もとりません**。パスワードや鍵は受け取りません
- Actions の分は、走らせた人ではなく **リポジトリの持ち主（貸し手）** に付きます。書き込みのできる人は誰でも走らせられます
- GitHub のランナーで走らせてよいのは、そのリポジトリのソフトウェアの開発・試験に関係することだけ。なのでホストには
  ラボそのものを送り、ラボの試験だけを走らせます

## 貸し手がすること

```sh
node lab.mjs host template ./bds-lab-host     # 貸し手に渡す 3 つのファイル（README.md・host.yml・.lab-host.json）
```

1. この 3 つで **private** のリポジトリを作る（GitHub のテンプレートにしておけば「Use this template」で作れます）
2. あなたを collaborator（Write）に招く
3. `.lab-host.json` を書く: `minutesPerMonth`（1 か月に貸す分。ラボはその **80%** で止まる）・`jobs`（許す仕事）・
   `hours`（時間帯、`22:00-06:00` のように日をまたいでも可）・`timezone`・`until`（最後の日）・`contact`。
   あわせて自分の GitHub の予算（Settings → Billing → Budgets）も決めておく

## あなたがすること

```sh
node lab.mjs host add lender/bds-lab-host     # 書き込めるか・.lab-host.json が正しいか・host.yml がひな形と同じか
node lab.mjs host                             # ホストごとの今月の分 / 止める分 / 上限・許す仕事・時間帯・期限
node lab.mjs host run gate                    # 残りの多いホストで、ラボの試験（gate）を
node lab.mjs host run test -a ruby --on lender/bds-lab-host   # 自分のユニットの試験をそのホストで
node lab.mjs host results                     # 結果（途中で切れた run も、ここで続きから受け取る）
node lab.mjs host report lender/bds-lab-host  # 貸し手への月の報告（数だけ）。--issue でホストの Issue に（確かめてから）
```

仕事（`jobs`）: `gate`（ラボの試験）・`gate-all`（全部の試験）・`test` `go` `sim`（自分のユニット: `-a`）・`upkeep`・`dev-bds`。
AI を使う仕事（make・harden）とアカウントの要る app ラボは、ホストでは走らせません。

1 回の仕事: ラボ（リリースと同じ中身: 見本以外のユニット・キャッシュ・秘密は入らない。ラボ自身の CI は `.lab-github/` に
置くので GitHub は何も始めない。gate はあなたの `auto policy` の一覧）と、`-a` のユニット（share が配らないものは入れない）を、
ホストの作業の枝 `lab/run-<番号>` に送る → `host.yml` を始める → 待つ → 結果（JSON と伏せ字のログ）を受け取る → かかった分を
`auto/host-ledger.jsonl` に書く → 枝を消す。結果は `.lab/host-results/<番号>/` に。見つけた実行の番号は台帳に書くので、
途中で切れても `host results` がその実行を見に行きます。GitHub が答えない（回線・レート制限）だけでは「無くした」にしません。

## ブラウザから（管理パネル）

貸し手も借り手も、自分の GitHub のトークンで [管理パネル](../../panel/README.md) に入れます（ホストの持ち主 = 貸し手、
ホストに書き込める人 = 借り手。ラボのリポジトリに入れない人でも、ホストがあれば使えます）。「貸し借り」で:

- **借り手**: ホストごとの今月の分（ホストの host.yml の実行から、ホストの時間帯の月で）と止まるところ（上限の 80%）・
  いま使えるか（期限・時間帯・走っている仕事）・最近の結果
- **貸し手**: 上のほかに、`.lab-host.json` をその場で変える（1 か月の分・許す仕事・時間帯・時間帯の地域・最後の日・連絡先。
  ラボと同じ検査を通ってから書く）。「今すぐ止める」は最後の日を昨日に、「再開する」は選んだ日に（新しい項目は増やさないので、
  ひな形から作ったどのホストでも、host.yml も借り手のラボもそのまま止まります）

## 止まるとき

- 上限の 80% に届く（今月の分 + この仕事の見込み）・期限を過ぎた・許されていない仕事・時間帯の外・同じホストで別の仕事が
  走っている → そのホストは使いません。理由と、ほかのホストか自分の場で走らせる案を出します
- ホストが 403/404 を 2 回続けて返す（招待を外された・消された）→ もう使いません（1 回目はその回だけ使わない。また見える
  ようになれば使います）。レート制限・組織の SSO・回線の不調は貸し手のせいではないので、その回だけ使いません
- 書き込めなくなった・アーカイブされた・`.lab-host.json` が無いか正しくない → 直るまで使いません（前の決まりで続けません:
  貸し手が止めたのかもしれないので）
- 送る前の検査（share と同じ秘密の検査を、名前によらず小さな文字のファイル全部に）: `.env.*`・鍵（`.pem` `.key` `.p12`
  `.pfx`・SSH の鍵）・認証のファイル・BDS の zip・借りたアドオン（印・`borrowed_` の名前・`.borrowed/`）・app ラボの結果・
  大きすぎるファイルがあれば、何も送らずに止まり、どのファイルかを言います（秘密そのものは表示しません）
- ホストの側でも、`host.yml` が既定の枝の `.lab-host.json` を読み、許されていない仕事・時間帯・期限なら走らせません

## 自動操縦から

`node lab.mjs auto policy gateOn=auto`（または `gateOn=<owner/repo>`）にすると、ラボ自身への変更の gate をホストで走らせます。
ホストで通れば通り、落ちたか、どのホストも使えないときは、いままで通り手元の gate が決めます。`node lab.mjs auto gate --on auto`
で手で頼むこともできます。`node lab.mjs auto` に、ホストごとの今月の分が出ます。

## 心づもり

- 送ったもの（ラボと自分のユニット）は貸し手に見えます。public のホストなら標準のランナーの分は掛かりませんが、送ったものも
  公開になります
- 結果は「貸し手の場で出たもの」です。リリースを決めるときは、自分の場でも 1 回確かめてください
